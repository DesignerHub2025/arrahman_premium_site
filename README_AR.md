# الموقع الجديد لمسجد الرحمن الرحيم — أولاد فايت

النسخة الجديدة مبرمجة باستخدام HTML/CSS/JavaScript، بدون مكتبات ثقيلة. تصميم متجاوب مع الهاتف والحاسوب، وواجهتان عربية وفرنسية، وساعة محلية للجزائر، وروابط موقع Google Maps ومواقيت مسجد الرحمن الرحيم على Mawaqit وصفحة Facebook.

## التجربة
افتح `index.html` في متصفح. الموقع يعمل دون خادم لمعظم الميزات؛ خريطة Google ومواقيت Mawaqit وخطوط Google وروابط Facebook تحتاج اتصالًا بالإنترنت.

## النشر
ارفع **كامل المجلد** إلى استضافة مثل Netlify أو GitHub Pages أو استضافة موقع عادية، مع الحفاظ على أسماء الملفات. ملف `manifest.webmanifest` و `sw.js` يساعدان على تثبيت الموقع والعمل دون اتصال للصفحات الأساسية عندما يتم النشر عبر HTTPS.

- Facebook: https://www.facebook.com/share/1J8AvCJcKi/

- وصف العنوان: حي 80 مسكن، هضبة أولاد فايت، الجزائر العاصمة، وفق النص السابق للموقع. يُرجى مراجعته مع إدارة المسجد قبل النشر الرسمي.

## ملاحظات قبل الاعتماد النهائي
- رمز المسجد في الموقع رمز هندسي أصلي مُصمَّم للموقع، **وليس الشعار الرسمي**؛ يمكن استبداله عند تقديم الشعار الحقيقي.
- الرسم الرئيسي للمسجد رمزي ولا يمثّل صورة المبنى الحقيقي.
- خريطة Google المضمّنة تعتمد على Plus Code منشور للمسجد؛ يبقى الرابط المباشر الذي قدمتموه هو المرجع عند التنقّل.
- مواقيت الصلاة لا يتم تقديرها هنا؛ زر المواقيت يفتح صفحة Mawaqit الخاصة بالمسجد.
- لا توجد وظائف إدارة محتوى أو تسجيل/دفع أو لوحة تحكم حالياً.
